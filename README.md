# ⚡ YohanX Super - POS System

**YohanX Super** kiyanne Garment & Clothing business wala Retail, Wholesale, and In-house production lesiyen manage karanna hadapu lightweight Point of Sale (POS) and Inventory Management web system ekak[cite: 1, 2].

---

## ✨ Features

- **🛒 Dual-Pricing POS Interface:** Retail vs Wholesale price lesiyen checkout ekedima toggle kirima[cite: 2].
- **📦 Inventory Management:**
  - **Purchased Items:** Vendor price + shipping + margin tracking[cite: 2].
  - **Manufactured Items:** Material cost + tailoring cost + margin tracking[cite: 2].
- **📊 Real-time Dashboard:** Daily sales, low-stock alerts, profit/loss tracker[cite: 2].
- **💳 Payment Methods:** Cash, Card, Bank Transfer and Receipt printing[cite: 2].
- **👥 Credit Tracking:** Wholesale credit customers la ge naya/debt tracking[cite: 2].
- **🌙 Modern UI:** Responsive Dark Mode interface[cite: 1].

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS[cite: 1]
- **Storage/DB:** Dexie.js (IndexedDB wrapper)[cite: 1]
- **Icons & Fonts:** FontAwesome 6, Inter Font[cite: 1]
- **Scripting:** Modular Pure JavaScript[cite: 1]
